# Glossário pt-BR → en-US deste repositório.

# Existe porque a mesma cadeia saiu traduzida de jeitos diferentes na MESMA
# página, três vezes: "ofício · proposta" virou "craft", "profession" e ficou
# intacto; os quatro rótulos de campo saíram em SEIS variantes; e
# "registrador (latch)" virou "register (latch)" no texto e "latch (latch)" no
# rótulo do SVG. Tradução bloco a bloco não tem como saber que uma cadeia é
# vocabulário fechado — quem sabe é esta lista.
#
# Uma linha por termo. O tradutor recebe isto como "use exatamente estas
# formas".
